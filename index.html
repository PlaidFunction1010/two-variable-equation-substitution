聯立方程式練習區 代入消去法

步驟：先用一條式子拿到 x 或 y，再代入另一條式子 → 解出另一個變數 → 寫出(x, y)

題目 / Question (整數解，可能有負數)

例如：
式(1)：x = 3
式(2)：2x + y = 9
正解：(x, y) = (3, 3)
請按「出題」
▶ 顯示 / 隱藏 詳解
（詳解會出現在這裡）
代入消去法：先把「已經解好的那個變數」帶進另一條式子，就像把答案塞進機器裡算出另一個未知數。
