聯立方程式練習區 代入消去法｜第一型

步驟：用「只有一個變數」的那條式子先拿到 x 或 y，代入另一條式子，再解出 (x, y)

題目 / Question

例如： 式(1)：x = 3 式(2)：2x + y = 9 正解：(x, y) = (3, 3)

聯立方程式練習區 代入消去法｜第二型

將式(1) 變成 y = ax + b（或 x = ay + b），再代入式(2) 解出 (x,y)

題目 / Question

範例： 式(1)：2x - y = 3 式(2)：2x + y = 9 正解：(x, y) = (3, 3)
