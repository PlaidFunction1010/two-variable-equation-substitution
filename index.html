步驟：用「只有一個變數」的那條式子先拿到 x 或 y，代入另一條式子，再解出 (x, y)

題目 / Question

例如： 式(1)：x = 3 式(2)：2x + y = 9 正解：(x, y) = (3, 3)

聯立方程式練習區 代入消去法｜第三型

兩條方程式長得像 \( \frac{a}{x} + \frac{b}{y} = c \)。
設 \(U=\frac{1}{x}, V=\frac{1}{y}\)，先解 U 和 V，再回推 x 和 y。

題目 / Question

範例： 式(1)：\( \frac{2}{x} + \frac{1}{y} = 3 \) 式(2)：\( \frac{1}{x} + \frac{2}{y} = 3 \) 正解：(x, y) = (1, 1)
